# 提示词工作台（离线 Skill）

把用户的一句话需求，变成一段**可以直接粘进任何 AI 使用**的提示词。

## 优先级规则

1. **如果环境里配置了 MCP 服务器 `prompt-workbench`**，直接用它的工具，不要读 references：
   `recommend_scene` / `list_scenes` → `get_questionnaire` → `render_prompt`。
2. 没有 MCP 时，按下面的本地流程走，按需读取 `references/scenes/<id>.md`。

## 本地流程（严格按顺序）

1. **选场景**：对照 `references/scenes-index.md` 匹配用户需求；匹配不到就问一句「你想解决哪类问题」并给出 3 个候选。
2. **读该场景**：打开 `references/scenes/<id>.md`，里面有「问题清单」和「模板」。
3. **逐个提问**：一次只问一个问题，等用户回答再问下一个。用户说「跳过 / 不知道」时，用推荐答案或默认假设继续，并明确标注「假设」。
4. **渲染成品**：必填项齐了（或都已标为假设）之后，把模板里的 `{{key}}` 替换成用户回答的原文，输出成品提示词。
5. **输出三段**：① 成品提示词（放在代码块里，方便复制）② 缺失项与假设 ③ 下一步建议。

## 硬性约束

- 不要一次抛出多个问题；每轮只问一个。
- 不要编造用户没有提供的材料、数字、版本号；缺的地方写「待确认」。
- 模板里的「（未提供，请先向用户确认）」在生成成品前必须被回答或标为假设。
- **先给能用的最小版本，再列需要确认的信息（最多 3 条）；不要只追问不产出。**
- 成品提示词必须包含：角色 / 任务 / 已知信息 / 输出格式 / 约束；不得掺入解释性废话。
- 场景库的借鉴来源写在 `references/sources.md`，不要声称这些方法全部原创。

## 场景索引

| id | 场景 | 什么时候用 |
| --- | --- | --- |
| `requirement-clarify` | 把模糊需求说清楚 | 脑子里有个想法但说不清要做成什么样；或者别人只给你一句话，你不知道从哪开始。 |
| `coding-task` | 把任务变成 AI 能执行的开发任务 | 要把一个开发任务交给 AI 写代码，但说太粗它乱改、说太细自己又费劲。 |
| `document-writing` | 把一句话要求变成写作提示词 | 要写报告、总结、通知、文案，但直接丢给 AI 得到的东西又空又套话。 |
| `debug` | 报错了，帮我定位 | 代码跑不起来、报错看不懂、或者行为和你预期不一样，卡了半小时以上。 |
| `code-review` | 帮我审这段代码 | 写完一段代码不确定质量，或者合并前想让人挑一遍问题。 |
| `refactor-plan` | 这段代码该重构了，给我一个计划 | 代码越改越难受、加个功能要动五个地方、或者想整理但不敢动。 |
| `test-design` | 帮我想测试用例 | 功能写完了不知道怎么测，怕漏掉边界；或者要给别人的代码补测试。 |
| `api-integration` | 要对接一个第三方 API，怎么开始 | 要接支付、地图、AI、短信、开放平台等外部接口，文档看着头大。 |
| `code-explain` | 让 AI 把这段代码讲清楚 | 接手别人的代码、看开源项目源码、或者自己以前写的代码看不懂了。 |
| `bug-report` | 把这个 bug 写成能复现的 issue | 要提 issue / 向别人报障 / 交给 AI 修，但你现在只会说「它坏了」。 |
| `perf-opt` | 它太慢了，怎么优化 | 页面加载慢、接口返回慢、数据一多就卡，但不知道瓶颈在哪。 |
| `security-check` | 帮我做一次安全自查 | 项目要公开、要给同学/客户用、或者代码里有 key 和用户数据。 |
| `deploy-ci` | 把这个项目部署上线（带自动测试） | 本地能跑，但不知道怎么发布到网上；或者每次发布都手动，容易漏。 |
| `tech-select` | 这个技术选型，帮我做决定 | 在两个库/框架/方案之间纠结，怕选了之后回不了头。 |
| `data-analysis` | 这堆数据，帮我分析出结论 | 手上有表格/日志/问卷数据，想知道它说明了什么，但不想只贴个平均数。 |
| `research-compare` | 帮我调研这几个东西，给个结论 | 要调研新技术/竞品/方案，但不想看完 20 篇文章还不知道结论。 |
| `learn-tech` | 帮我排一个学新技术的计划 | 想学一个新东西（语言/框架/工具），但一打开教程就迷路，学完又不会用。 |
| `agent-task` | 把这个任务交给 AI Agent 去执行 | 想让编码 Agent（CodeBuddy / Cursor / Claude Code 等）帮你做一件完整的事，但怕它乱改。 |
| `tech-doc` | 帮我写技术文档 / README | 项目要给人看，但没有 README；或者要写设计文档、接口文档、周报。 |
| `meta-prompt` | 把我的任务变成一段提示词 | 你要让 AI 做一件具体的事，但不知道该怎么开口，或者以前问过效果很一般。 |

共 20 个场景。新增场景请改 `data/scenes/`，然后跑 `npm run build:skills`，不要手改本文件。
