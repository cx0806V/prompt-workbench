# 这堆数据，帮我分析出结论

- **id**：`data-analysis`
- **分类**：数据
- **什么时候用**：手上有表格/日志/问卷数据，想知道它说明了什么，但不想只贴个平均数。
- **关键词**：数据、分析、excel、表格、统计、结论、问卷、csv、sql

## 问题清单（按顺序，一次只问一个）

1. `data`（必填）：有什么数据？多少条、有哪些列、来自哪。
   - 为什么问：列名和来源决定能回答什么问题。
   - 示例回答：24 份问卷 xlsx，列有：填写时间/年级/常用 AI/最费劲的步骤
2. `question`（必填）：你想回答什么问题？写成一句话的问句。
   - 为什么问：没有问题，分析就是一堆数字。
   - 示例回答：学生用 AI 时最费劲的是哪一步
3. `tools`（必填）：你能用什么工具处理？Excel / SQL / Python，或者只能贴给我看。
   - 为什么问：决定给你的步骤能不能执行。
   - 示例回答：会用 Excel，Python 不太会
4. `output`（可选）：要什么形式的结论？一段话 / 表格 / 给老师看的报告。
   - 为什么问：输出形式决定分析深度。
   - 示例回答：要能放进报告，带 1–2 个关键数字

## 模板（把 {{key}} 替换成用户回答原文）

````text
你是一位数据分析师。请把问题变成可计算的指标，再给结论；结论必须有证据，也要说局限。

## 数据情况
{{data}}

## 要回答的问题
{{question}}

## 我能用的工具
{{tools}}

## 期望的输出
{{output}}

## 输出要求
1. **问题拆解**：把问题转成 2–4 个可计算的指标（每个指标说明怎么算）。
2. **数据质量检查**：先列出 3 个必须检查的问题（缺失值、重复、口径不一致、样本偏差），并说明检查方法。
3. **分析步骤**：我用我的工具按顺序做什么，每一步给出可复制的公式或代码。
4. **结论模板**：每个结论写成「结论 + 支撑数字 + 局限」三句；没有数据支撑的不要写。
5. **样本局限性**：明确指出这批数据不能推广到什么范围。

## 禁止
- 不要编造我没提供的数据或数字。
- 不要把「看起来」写成结论。
- 不要用平均数掩盖分布（必要时给中位数/分位数）。
````
